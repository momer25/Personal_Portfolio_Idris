About Gharo Project

Language is a bridge between memory and possibility.

Gharo Project brings English, Tigre, and Arabic together in a focused reference built for everyday language discovery.

The purpose

A reference built for everyday language.

Gharo Project was created to make multilingual lookup easier for learners, families, educators, and communities. The dictionary connects a growing archive of English words with Tigre and Arabic translations in a simple, accessible experience.

The project is intentionally practical: search quickly, read the context, compare languages, and keep learning. It is also a living resource, open to thoughtful corrections and additions from people who know and use the language.
